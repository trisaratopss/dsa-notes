# DSA Notes

Personal notes and problem log while relearning data structures & algorithms for internship prep.

## How this is organized

Folders are numbered in the order to work through them — each stage builds on the last, so it's worth going roughly in order rather than jumping around.

1. Arrays, Strings, Sorting, Binary Search
2. Hashmaps
3. Two Pointers & Sliding Window
4. Stacks, Queues, Intervals
5. Linked Lists
6. Recursion & Backtracking
7. Trees & Tries
8. Heaps / Priority Queues
9. Graphs
10. Dynamic Programming & Greedy
11. Bit Manipulation, Math, Design Problems

## Template

Each topic file has four sections:
- **What it's good/bad for** — plain-language summary, no copy-pasted definitions
- **Time & Space Complexity** — filled in as a table
- **Recognition triggers** — what in a problem statement should make you think "this is a ___ problem"
- **Problems solved** — checklist with a one-line pattern note per problem, not full solutions
